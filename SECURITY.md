# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in VRViewer or this repository, please report it privately.

**Preferred method:** Use GitHub's private vulnerability reporting feature:
https://github.com/leethemaxuser/VRViewer-Public/security/advisories/new

Please do not report suspected vulnerabilities in a public GitHub Issue or Discussion until the issue has been assessed and coordinated.

When reporting a vulnerability, include:
- A description of the issue and its potential impact
- The affected VRViewer version or repository component
- Steps to reproduce the issue, if safe to provide
- Any relevant screenshots, logs, or proof-of-concept details that do not expose personal information or other users' data

Do not include passwords, license keys, private access tokens, or unrelated sensitive information.

## Scope

This repository is primarily intended for public releases, documentation, and support. Reports may concern VRViewer, its installer, or files published in this repository.

## Response

LTM Technologies will review reports as circumstances permit. A report does not guarantee a particular response time, fix, or release date. Please allow reasonable time for assessment before publicly disclosing details.

Thank you for helping keep VRViewer and its users secure.
